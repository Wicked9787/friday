# Friday

A personal assistant that lives on the iPhone Home Screen as a web app, hosted on free GitHub Pages.

**Live address (after you enable Pages):** https://wicked9787.github.io/friday/

- Sky: https://wicked9787.github.io/friday/?u=sky
- Batsie: https://wicked9787.github.io/friday/?u=batsie

Start with **docs/SETUP-SKY.md**. Batsie’s steps are in **docs/SETUP-BATSIE.md**. Widgets are in **docs/SCRIPTABLE.md**. Architecture and a file map are in **docs/NOTES.md**.

There is no API key in this repository. Each phone enters its own Groq key on first launch.


This folder is a standalone copy with the **sky** profile already chosen, so you do not need ?u=sky. You can still pass ?u= to switch.
