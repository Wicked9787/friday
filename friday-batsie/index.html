    Wake with Back Tap

    Double-tap the back of your iPhone and she opens already listening. No Siri needed.

    1. In Shortcuts, tap +, add Open URLs, and type friday://listen. Name it Wake Friday.
    2. Open iPhone Settings → Accessibility → Touch → Back Tap → Double Tap and pick Wake Friday.

    Back Tap works when the phone is unlocked. You can also put Friday in your Dock: press and hold the icon and drag it down.

    Shortcut setup
    1. Tap Copy prompt.
    2. Open the Shortcuts app. Delete your old shortcut named Friday (press and hold it, then Delete).
    3. Tap + to make a new shortcut, and paste the prompt into the box that asks what the shortcut should do.
    4. Name the new shortcut exactly Friday.
    5. Check there is no Speak Text step. Run it once from Shortcuts and allow Home, Messages, Contacts, Calendar, Reminders, Music, Clock, and Focus when it asks.
    Timers of 10 minutes or more are also handed to your Shortcut, so they ring even if the app is closed.
    Used when Friday needs to set alarms, lights, and other phone jobs.
    Routines

    Say the phrase and she does every step, in order. Steps are ordinary commands, one per line. You can also say several things at once anytime, like “lights to 40%, add milk and set a timer for 10 minutes”.

    Read my texts and emails out loud

    iPhone doesn't let apps read other apps' notifications, but a one-time automation can hand her texts or emails from the people you pick.

    1. Shortcuts → Automation → + → Message (or Email). Pick the people.
    2. Run Immediately → New Blank Automation.
    3. Add URL Encode on Shortcut Input, then add Open URLs with friday://msg?kind=text&from=, then the Sender variable, then &text=, then the URL Encoded Text variable.

    She'll say “Text from Mom: …”. For emails use kind=email.

    Pick a style, then copy its script into Scriptable. You can have several widgets with different styles.
    Widgets and Control Center

    Home Screen and Lock Screen

    1. Install the free Scriptable app.
    2. Tap Copy widget script below, open Scriptable, tap +, paste, and name it Friday Widget.
    3. Long-press your Home Screen → Edit → Add Widget → Scriptable. Pick a size, add it, tap it, and choose the script.
    4. Lock Screen: long-press the Lock Screen → Customize → Lock Screen → add Scriptable widgets, then pick Friday Lock Screen for each.

    Control Center

    1. Swipe down from the top-right corner, tap + at the top left, then Add a Control.
    2. Search Open App, add it, and choose Friday. One tap opens her listening.
    3. Add another control, search Shortcut, and choose your Friday shortcut to run phone commands from anywhere.
    4. You can also put these on the Lock Screen's bottom buttons and the Action button.
    A reminder for the Scriptable widget parameter. It does not change the widget by itself.

    About & updating

    This app is a website you keep on GitHub Pages. The live site is wicked9787.github.io/friday. Sky’s copy opens with ?u=sky. Batsie’s copy opens with ?u=batsie.

    The Groq key stays on this phone. Never paste it into a file you upload.

    What each part is

    • index.html, css/app.css, and the files in js/ — the app itself.
    • config.js — names, looks, layouts, and the default bubbles for Sky and Batsie.
    • sw.js — the offline copy. After you change files, bump the cache name at the top (for example to friday-shell-v4) so phones pick up the new version, or use Check for updates.
    • icons/ and icons/choices/ — Home Screen icons.
    • profiles/ — unsigned Web Clip files that add the icon to the Home Screen.
    • scriptable/ — the widget scripts. Batsie’s copy in friday-batsie/scriptable/ should keep ?u=batsie.
    • friday-sky/ and friday-batsie/ — standalone copies that are already set to one person.
    • docs/ — setup guides and HOW-TO-UPDATE.md, a longer version of this page.

    How to change something

    On a computer or in the GitHub website, open the Wicked9787/friday repo, edit a file, and commit it to main. Wait a minute, then tap Check for updates in this Settings page.

    You can also ask a free AI helper to edit a file you paste in, then upload that file back on GitHub. A short walkthrough is in the how-to-update guide.
